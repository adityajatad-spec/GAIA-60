# gaia-agent

A modular CLI research agent that answers complex, multi-step questions by chaining tool use — web search, web browsing, code execution, and file parsing. Built for the [GAIA benchmark](https://huggingface.co/datasets/gaia-benchmark/GAIA) with pluggable LLM providers, self-verification, and an evaluation harness.

## Features

- **Pluggable providers** — Ollama (local), Anthropic Claude, OpenAI GPT; switch without touching agent logic
- **Tool use** — web search (Tavily), web browsing (trafilatura), sandboxed Python execution, file reading (PDF/DOCX/XLSX/images/text)
- **Self-verification** — second-pass check via the same or a different provider
- **Self-consistency voting** — run N independent rounds, pick the majority answer
- **Robust loop** — format-compliance retry, empty-response retry, tool-failure retry, browse-URL validation, context-overflow protection via snippet truncation
- **Step-budget awareness** — nudges the model at 70% of the limit to wrap up
- **Vision support** — attach images; providers with vision capability receive native image blocks, others get OCR text fallback
- **GAIA eval harness** — `eval/run_eval.py` with quasi-exact-match scoring, parallel workers, per-level summary

## Prerequisites

- Python 3.10+
- [Poetry](https://python-poetry.org/) (recommended) or venv
- At least one provider available:
  - **Ollama** (local, free) — `brew install ollama && ollama pull qwen3:8b-64k`
  - **Anthropic** (for scoring) — API key from [console.anthropic.com](https://console.anthropic.com)
  - **OpenAI** — API key from [platform.openai.com](https://platform.openai.com)
- **Tavily API key** for web search — [tavily.com](https://tavily.com)

## Quick Start

```bash
git clone git@github.com:adityajatad-spec/RESEARCH-COPILOT-1009.git
cd gaia-agent
cp .env.example .env

# With Poetry
poetry install && poetry shell

# Or with venv
python -m venv venv && source venv/bin/activate && pip install -r requirements.txt

# Run the interactive setup wizard
python -m agent.setup

# Ask a question
python -m agent "What is the capital of France?"
```

The setup wizard prompts for your provider choice, validates API keys before writing `.env`, and checks that the Ollama server + model are reachable if you choose that provider.

## Usage

### CLI Agent

```bash
# Single question
python -m agent "What is the capital of France?"

# Override model or step budget
python -m agent -m claude-sonnet-4-20250514 -s 20 "Your question"

# With attached files
python -m agent -f report.pdf "Summarise the key findings"

# Use a different provider for verification
python -m agent --verify-provider anthropic "Your question"

# Self-consistency voting (3 independent runs)
python -m agent --votes 3 "What is the capital of France?"
```

The agent prints each step live: model reasoning, tool calls, and results. When finished it writes a full JSON trajectory to `logs/<timestamp>.json`.

### GAIA Evaluation

```bash
# Point to your GAIA validation set
python eval/run_eval.py --data eval/data/gaia_validation.jsonl

# Filter by difficulty level
python eval/run_eval.py --level 1

# Limit to first N questions
python eval/run_eval.py --limit 10

# Use local Ollama for testing
python eval/run_eval.py --provider ollama --limit 1

# Run 4 workers in parallel (Anthropic)
python eval/run_eval.py --parallel 4
```

Results are written to `eval/results/<timestamp>.jsonl` with full trajectory per question.

### Diagnostics

```bash
python scripts/diagnose.py
```

Runs a 6-stage check (imports → server reachability → model availability → bare call → tool call → full loop) and prints a summary table.

## Configuration

All configuration is via `.env` in the project root (generated by the setup wizard):

| Variable                | Required         | Description                                  | Default              |
|-------------------------|------------------|----------------------------------------------|----------------------|
| `PROVIDER`              | Yes              | Active provider (`ollama`, `anthropic`, `openai`) | `ollama`       |
| `TAVILY_API_KEY`        | Yes              | Tavily search API key                        | —                    |
| `ANTHROPIC_API_KEY`     | For Anthropic    | Anthropic API key                            | —                    |
| `ANTHROPIC_MODEL`       | No               | Anthropic model                              | `claude-sonnet-4-20250514` |
| `OPENAI_API_KEY`        | For OpenAI       | OpenAI API key                               | —                    |
| `OPENAI_MODEL`          | No               | OpenAI model                                 | `gpt-4o`             |
| `OLLAMA_MODEL`          | No               | Ollama model                                 | `qwen3:8b-64k`       |
| `OLLAMA_HOST`           | No               | Ollama server URL                            | `http://localhost:11434` |

## Tool Reference

| Tool                 | Description                                          |
|----------------------|------------------------------------------------------|
| `search`             | Web search via Tavily API; snippet truncation at 500 chars |
| `browse`             | Fetch URL content via trafilatura (16k char limit)   |
| `code_exec`          | Isolated Python subprocess (10s timeout, sandboxed)  |
| `read_attached_file` | Read PDF/DOCX/XLSX/images/text files attached via `-f` |

### Security

- Code execution runs in a temporary directory with `open()` restricted to that directory and `socket()` blocked
- Browse calls are validated against URLs returned by prior search results (no guessed URLs)
- API keys are never logged or printed
- `.env` is gitignored
